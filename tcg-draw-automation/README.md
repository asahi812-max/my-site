# トレカ抽選情報の自動収集（初期版）

このフォルダは、ポケカ・ワンピカードの抽選候補を定期収集し、JSONにまとめるための初期版です。

## 動作
- GitHub Actionsで毎日1回実行
- Google Newsの公開RSSから、札幌・北海道を優先した抽選関連の記事候補を収集
- URL、タイトル、公開日時、取得日時をJSONに保存
- 条件や締切は、元の告知で確認するまで確定扱いにしない

## 注意
- これは候補収集です。抽選の有効性や募集継続中を自動で保証しません。
- Xの全投稿を収集するものではありません。X APIは無料利用条件を確認してから追加します。
- 応募フォームの自動送信、アカウントログイン、BOT回避は行いません。
- 既存のトレカ抽選ノートとは、現時点では直接同期していません。

出力先: `tcg-draw-automation/data/collected.json`
